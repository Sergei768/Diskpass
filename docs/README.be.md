# Diskpass

Генератар фізічных метак для носьбітаў інфармацыі і лакальная зашыфраваная база для кіравання архівам.

Diskpass дапамагае ўпарадкаваць HDD, SSD, флэш-назапашвальнікі і стужкі LTO без адкрытых надпісаў пра змесціва, спосаб шыфравання і паролі. Для кожнага носьбіта ствараецца кароткая метка накшталт `HK-T1R-BAM-LK-XYQ`. Уладальнік знаходзіць звязаны запіс у базе `.dpdb`; метка змяшчае кампактныя коды метаданых, але не пароль.

## Асноўныя магчымасці

- **Фізічныя меткі:** пяць кампанентаў — тып, ёмістасць, назва змесціва, метад шыфравання і соль носьбіта.
- **Схема асобнай базы:** пры стварэнні базы выбіраецца выпадковы парадак кампанентаў (`5! = 120` магчымых перастановак).
- **Улік архіва:** ручное і аўтаматычнае даданне дыскаў, паролі, нататкі, здымкі каталогаў і пошук па адключаных носьбітах.
- **Ахова базы:** кантэйнер DPENV5, XChaCha20-Poly1305 і OpenPGP/GPGME; ML-KEM залежыць ад падтрымкі GnuPG.
- **Дадатковыя сродкі:** стэганаграфія, блакіроўка, ачыстка буфера абмену, рэжым калькулятара і давераныя плагіны.

## Стварэнне фізічнай меткі

<img src="diagrams/tags.svg" width="100%" alt="Схема генерацыі фізічнай меткі"/>

Метка складаецца з пяці блокаў праз злучок. Кожны блок мае выгляд **`[КОД][КАНТРОЛЬНЫ_СІМВАЛ]`**; апошні сімвал вылічваецца з выкарыстаннем **BLAKE2b** і сакрэтаў базы `noise_key` і `salt`.

| Кампанент | Значэнне |
|---|---|
| `type` | Тып носьбіта: HDD, SSD, USB, LTO і інш. |
| `size` | Ёмістасць у выглядзе ўнутранага кода |
| `content_tag` | Карыстальніцкая метка змесціва |
| `cipher` | Метад шыфравання носьбіта |
| `dsalt` | Выпадковае значэнне для асобнага дыска |

**Парадак дзеянняў:** выбар схемы → кадзіраванне значэнняў → генерацыя `dsalt` → вылічэнне кантрольных сімвалаў → зборка пяці блокаў. Прыклад `HK-T1R-BAM-LK-XYQ` у стандартным парадку азначае HDD, 1 TB, Backup, LUKS і соль `XY`.

## Шыфраванне базы `.dpdb`

<img src="diagrams/encryption.svg" width="100%" alt="Абарона зашыфраванай базы DPENV5"/>

Diskpass захоўвае паролі, нататкі, адпаведнасць метак, параметры схемы і індэксы файлаў у лакальным бінарным кантэйнеры **DPENV5**.

1. **Серыялізацыя:** `cJSON` фармуе структуру запісаў.
2. **Шыфраванне з аўтэнтыфікацыяй:** **XChaCha20-Poly1305** абараняе змесціва; загаловак уключаецца ў AAD.
3. **Ключавы канверт:** **OpenPGP/GPGME** абараняе ключавы матэрыял і звяртаецца да GnuPG/pinentry для прыватнага ключа.
4. **Подпіс:** хэш **BLAKE2b-256** дапамагае звязаць подпіс DPENV5 з дапоўненымі адкрытымі данымі.
5. **Кантроль версій:** ланцужок пакаленняў і лакальны anti-rollback-стан дапамагаюць выявіць старую копію базы.

Профіль **ML-KEM/Kyber** патрабуе сумяшчальнага OpenPGP-рухавіка GnuPG. **Argon2id** асобна ўжываецца для лічбавага кода рэжыму калькулятара і налад, а не для замены шыфравання `.dpdb`.

## Стэганаграфія

<img src="diagrams/steganography.svg" width="100%" alt="Убудаванне і выманне зашыфраванай базы"/>

Праграма ўбудоўвае **ўжо зашыфраваную** базу `.dpdb` у медыяфайл. Пасля вымання змесціва базы па-ранейшаму адкрываецца праз OpenPGP.

| Носьбіт | Спосаб убудавання |
|---|---|
| PNG, BMP, TIFF, lossless WebP і падобныя відарысы | Малодшыя біты RGB-пікселяў (LSB) |
| JPEG | Цотнасць асобных квантаваных AC DCT-каэфіцыентаў |
| WAV з цэлалікавым PCM | Адзін малодшы біт PCM-ўзору |
| MP3 | Наяўная вокладка APIC (ID3v2) |
| FLAC | Убудаваная вокладка PICTURE |

Новыя фарматы атрымліваюць bootstrap-seed з устойлівых даных носьбіта: гэта дазваляе знайсці схаваную `.dpdb` да разблакіроўкі. `DISKPASS_STEGO_MAX_PERCENT` абмяжоўвае запаўненне: па змаўчанні **20%**, дапушчальна **1–40**.

## Архітэктура і зборка

Праграма напісана на **C11**: **GTK3/GLib** — інтэрфейс; **libsodium** — выпадковасць і праца з адчувальнай памяццю; **GPGME/GnuPG** — OpenPGP; **cJSON** — серыялізацыя; **libjpeg/libwebp** — апрацоўка відарысаў. Плагіны ABI v1 дадаюць дзеянні ў меню; сярод іх — друк метак на Katasymbol E11 праз Bluetooth LE.

**Debian / Ubuntu:**

```bash
sudo apt install build-essential pkg-config libgtk-3-dev libglib2.0-dev \
  libgpgme-dev libsodium-dev libcjson-dev libjpeg-dev libwebp-dev

git clone https://github.com/Sergei768/Diskpass.git
cd Diskpass
make -j2
./diskpass
```

`./build.sh` прызначаны для ўсталявання ад імя звычайнага карыстальніка; не запускайце яго праз `sudo`. Пакетны скрыпт `diskpass-package.sh` патрабуе адпаведных інструментаў зборкі.

## Мадэль пагроз і ліцэнзіі

Разглядаецца пасіўны назіральнік, які бачыць фізічны носьбіт і метку, але не мае сакрэтаў базы або прыватнага OpenPGP-ключа. Метка — гэта **псеўданімізаваныя метаданыя, не шыфратэкст**: паўторы і даўжыня блокаў могуць мець статыстычныя заканамернасці. Diskpass не шыфруе файлы на самім дыску, не гарантуе незаўважнасць стэганаграфіі і не абараняе скампраметаваны камп'ютар. Натыўныя плагіны не ізаляваныя пясочніцай.

Асноўны код мае ліцэнзію **BSD-3-Clause**, а аб'яднаная праграма ўключае калькулятар з ліцэнзіяй **GPL-3.0-or-later** (`calculator/COPYING`).
