# Diskpass

Генератор захищених фізичних міток і локальна зашифрована база для архівів носіїв інформації.

Diskpass допомагає впорядкувати HDD, SSD, флешнакопичувачі та стрічки LTO без нанесення на них відкритих описів, методів шифрування чи паролів. Для кожного носія створюється коротка мітка, наприклад `HK-T1R-BAM-LK-XYQ`. Власник знаходить відповідний запис у зашифрованій базі `.dpdb`; сама мітка містить компактно закодовані метадані, а не пароль.

## Основні можливості

- **Фізичні мітки:** п’ять компонентів — тип, місткість, назва вмісту, метод шифрування та випадкова сіль носія.
- **Схема кожної бази:** порядок компонентів випадково вибирається під час створення бази; можливі `5! = 120` перестановок.
- **Керування архівом:** ручне або автоматичне додавання носіїв, паролі, нотатки, знімки каталогів, пошук по від’єднаних дисках і збереження показників SMART.
- **Захист бази:** DPENV5, XChaCha20-Poly1305 та OpenPGP/GPGME; підтримка ML-KEM залежить від версії GnuPG.
- **Додаткові функції:** стеганографія, автоматичне блокування, очищення буфера обміну, режим калькулятора та довірені нативні плагіни.

## Формування фізичних міток

<img src="diagrams/tags.svg" width="100%" alt="Схема формування фізичної мітки"/>

Мітка складається з п’яти блоків, розділених дефісами. Кожен блок має вигляд **`[КОД][КОНТРОЛЬНИЙ_СИМВОЛ]`**. Контрольний символ обчислюється з використанням BLAKE2b і параметрів `noise_key` та `salt` бази.

| Компонент | Призначення |
|---|---|
| `type` | Тип носія: HDD, SSD, USB, LTO тощо |
| `size` | Місткість у вигляді короткого внутрішнього коду |
| `content_tag` | Користувацька мітка вмісту |
| `cipher` | Метод шифрування носія |
| `dsalt` | Випадкове значення для конкретного носія |

**Алгоритм:** створити схему з п’яти полів → закодувати значення → згенерувати `dsalt` → додати контрольний символ до кожного блока → розташувати блоки за схемою. Для прикладу `HK-T1R-BAM-LK-XYQ` компоненти у звичному порядку означають HDD, 1 TB, Backup, LUKS і сіль `XY`.

## Шифрування бази `.dpdb`

<img src="diagrams/encryption.svg" width="100%" alt="Захист бази DPENV5"/>

Diskpass зберігає паролі, нотатки, відповідність міток, схему та індекси файлів у локальному двійковому контейнері **DPENV5**.

1. **Серіалізація:** `cJSON` формує структуру записів.
2. **Симетричне шифрування:** **XChaCha20-Poly1305** забезпечує шифрування з автентифікацією; заголовок враховується як AAD.
3. **Ключовий конверт:** **OpenPGP/GPGME** захищає ключовий матеріал, а GnuPG/pinentry працює з приватним ключем.
4. **Підпис та хеш:** **BLAKE2b-256** пов’язує підпис DPENV5 з доповненим відкритим текстом.
5. **Перевірка версій:** ланцюжок поколінь і локальний стан anti-rollback допомагають виявляти повернення до старої копії.

**ML-KEM/Kyber** доступний лише з відповідним профілем OpenPGP та сумісним рушієм GnuPG. **Argon2id** використовується окремо для коду доступу до режиму калькулятора й захисту налаштувань, а не замість шифрування `.dpdb`.

## Стеганографія

<img src="diagrams/steganography.svg" width="100%" alt="Вбудовування і вилучення зашифрованої бази"/>

У медіафайл вбудовується **вже зашифрована** база `.dpdb`. Після вилучення для її відкриття все одно потрібен відповідний OpenPGP-ключ.

| Носій | Спосіб вбудовування |
|---|---|
| PNG, BMP, TIFF, lossless WebP та інші зображення | Молодші біти RGB-пікселів (LSB) |
| JPEG | Парність вибраних квантованих AC DCT-коефіцієнтів |
| WAV з цілочисельним PCM | Один молодший біт кожного семпла |
| MP3 | Наявна обкладинка APIC у ID3v2 |
| FLAC | Вбудована обкладинка PICTURE |

Для нових форматів bootstrap-seed виводиться зі стабільних даних носія, що дозволяє знайти контейнер до розблокування бази. Ліміт заповнення задає `DISKPASS_STEGO_MAX_PERCENT` (типово **20%**, можливі значення **1–40**).

## Архітектура та збирання

Застосунок написаний мовою **C11**: **GTK3/GLib** забезпечує інтерфейс, **libsodium** — випадкові значення й роботу з чутливою пам’яттю, **GPGME/GnuPG** — OpenPGP, **cJSON** — серіалізацію, **libjpeg/libwebp** — обробку зображень. Плагіни ABI v1 можуть додавати дії до меню; приклад — друк міток на Katasymbol E11 через Bluetooth LE.

**Debian / Ubuntu:**

```bash
sudo apt install build-essential pkg-config libgtk-3-dev libglib2.0-dev \
  libgpgme-dev libsodium-dev libcjson-dev libjpeg-dev libwebp-dev

git clone https://github.com/Sergei768/Diskpass.git
cd Diskpass
make -j2
./diskpass
```

Для встановлення в каталог користувача використовуйте `./build.sh` (не запускайте його через `sudo`; інсталятор може потребувати додаткових залежностей). Сценарій `diskpass-package.sh` створює пакети за наявності інструментів відповідної платформи.

## Модель загроз і ліцензії

Модель загроз розглядає стороннього спостерігача, який бачить носії та мітки, але не має доступу до секретів бази й приватного OpenPGP-ключа. Мітка — це **псевдонімізовані метадані, а не шифротекст**; повтори й довжина блоків можуть відкривати закономірності. Diskpass не шифрує дані на самому диску та не захищає від компрометації робочої станції або ключа. Стеганографія не гарантує непомітності; нативні плагіни працюють без ізоляції.
