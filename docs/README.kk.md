# Diskpass

Ақпарат тасымалдағыштарының физикалық белгілерін жасайтын және жергілікті шифрланған мұрағат базасын басқаратын бағдарлама.

Diskpass HDD, SSD, USB-жинақтауыштар мен LTO таспаларын мазмұнды, шифрлау тәсілін немесе құпиясөзді сыртқы белгіге ашық жазбай тіркеуге көмектеседі. Әр тасымалдағышқа `HK-T1R-BAM-LK-XYQ` сияқты қысқа белгі беріледі. Иесі `.dpdb` шифрланған базасынан тиісті жазбаны табады; белгінің өзінде құпиясөз емес, ықшам кодталған метадеректер болады.

## Негізгі мүмкіндіктер

- **Физикалық белгілер:** тасымалдағыш түрі, сыйымдылығы, мазмұн атауы, шифрлау әдісі және жеке тұз мәні.
- **Дерекқорға тән схема:** бес бөліктің реті база құрылғанда кездейсоқ таңдалады (`5! = 120` орналастыру нұсқасы).
- **Мұрағатты басқару:** жинақтауыштарды қосу, құпиясөздер мен жазбалар, қалталар тізімінің суреттері, ажыратылған дискілерден файл іздеу және SMART көрсеткіштерін сақтау.
- **Қорғалған дерекқор:** DPENV5, XChaCha20-Poly1305 және OpenPGP/GPGME; ML-KEM мүмкіндігі GnuPG қолдауына байланысты.
- **Қосымша құралдар:** стеганография, автоматты бұғаттау, алмасу буферін тазалау, калькулятор режимі және сенімді плагиндер.

## Физикалық белгіні қалыптастыру

<img src="diagrams/tags.svg" width="100%" alt="Физикалық белгіні құру схемасы"/>

Белгі дефиспен бөлінген бес блоктан тұрады. Әр блоктың пішімі — **`[КОД][БАҚЫЛАУ_ТАҢБАСЫ]`**. Соңғы таңба **BLAKE2b**, `noise_key` және базаның `salt` параметрі негізінде есептеледі.

| Бөлік | Мағынасы |
|---|---|
| `type` | HDD, SSD, USB, LTO сияқты тасымалдағыш түрі |
| `size` | Сыйымдылықтың ішкі қысқа коды |
| `content_tag` | Пайдаланушы берген мазмұн белгісі |
| `cipher` | Тасымалдағыштағы шифрлау әдісі |
| `dsalt` | Әр тасымалдағышқа берілетін кездейсоқ мән |

**Алгоритм:** өрістер ретін таңдау → мәндерді кодтау → `dsalt` жасау → әр блокқа бақылау таңбасын қосу → блоктарды біріктіру. Қалыпты ретте `HK-T1R-BAM-LK-XYQ` мысалы HDD, 1 TB, Backup, LUKS және `XY` тұзын білдіреді.

## `.dpdb` дерекқорын шифрлау

<img src="diagrams/encryption.svg" width="100%" alt="DPENV5 дерекқорын қорғау схемасы"/>

Diskpass құпиясөздерді, белгілер сәйкестігін, жазбаларды, схема параметрлерін және файл индекстерін жергілікті **DPENV5** екілік контейнерінде сақтайды.

1. **Сериялау:** `cJSON` жазбаларды құрылымға келтіреді.
2. **Аутентификацияланған шифрлау:** **XChaCha20-Poly1305** деректерді қорғайды; сыртқы тақырып AAD құрамына кіреді.
3. **Кілт конверті:** **OpenPGP/GPGME** кілт материалын қорғайды, GnuPG/pinentry жабық кілтпен жұмыс істейді.
4. **Қолтаңба:** **BLAKE2b-256** арқылы есептелген хеш DPENV5 қолтаңбасын толықтырылған ашық деректермен байланыстырады.
5. **Нұсқаларды тексеру:** ұрпақтар тізбегі мен жергілікті anti-rollback күйі ескі көшірмені анықтауға көмектеседі.

**ML-KEM/Kyber** үшін үйлесімді GnuPG/OpenPGP қозғалтқышы керек. **Argon2id** `.dpdb` орнына қолданылмайды: ол калькулятор режимінің кіру кодына және баптауларды қорғауға арналған.

## Стеганография

<img src="diagrams/steganography.svg" width="100%" alt="Шифрланған базаны енгізу және шығару"/>

Diskpass медиафайлдың ішіне **бұрыннан шифрланған `.dpdb`** базасын енгізеді. Шығарылған базаға қол жеткізу үшін бәрібір OpenPGP жабық кілті қажет.

| Тасымалдаушы файл | Енгізу тәсілі |
|---|---|
| PNG, BMP, TIFF, lossless WebP және ұқсас суреттер | RGB пиксельдерінің кіші биттері (LSB) |
| JPEG | Таңдалған квантталған AC DCT коэффициенттерінің жұптылығы |
| Бүтін санды PCM WAV | Әр үлгінің бір кіші биті |
| MP3 | Қолда бар APIC мұқабасы (ID3v2) |
| FLAC | Енгізілген PICTURE мұқабасы |

Жаңа форматтардағы bootstrap-seed тасымалдаушының тұрақты деректерінен алынады, сондықтан шифрланған контейнерді дерекқор ашылмай тұрып анықтауға болады. `DISKPASS_STEGO_MAX_PERCENT` әдепкіде **20%** (рұқсат етілгені **1–40**).

## Құрылымы және жинау

Бағдарлама **C11** тілінде жазылған: **GTK3/GLib** — интерфейс; **libsodium** — кездейсоқ мәндер мен сезімтал жад; **GPGME/GnuPG** — OpenPGP; **cJSON** — сериялау; **libjpeg/libwebp** — суреттерді өңдеу. ABI v1 плагиндері мәзірге әрекеттер қосады; Katasymbol E11 плагині Bluetooth LE арқылы белгілерді басып шығарады.

**Debian / Ubuntu:**

```bash
sudo apt install build-essential pkg-config libgtk-3-dev libglib2.0-dev \
  libgpgme-dev libsodium-dev libcjson-dev libjpeg-dev libwebp-dev

git clone https://github.com/Sergei768/Diskpass.git
cd Diskpass
make -j2
./diskpass
```

Қосымша пайдаланушы орнатуы үшін `./build.sh` скриптін кәдімгі пайдаланушы ретінде іске қосыңыз (`sudo` қолданбаңыз). `diskpass-package.sh` дистрибутивке тән жинау құралдарын қажет етеді.

## Қауіп моделі және лицензиялар

Модельде сыртқы бақылаушы физикалық белгілерді көре алады, бірақ дерекқор құпиялары мен OpenPGP жабық кілтіне ие емес. Белгі — **псевдонимделген метадерек, шифрмәтін емес**: қайталанатын кодтар мен блок ұзындығы заңдылықтарды көрсетуі мүмкін. Diskpass дискінің ішіндегі файлдарды шифрламайды, стеганографияның байқалмайтынына кепілдік бермейді және бұзылған компьютерден қорғамайды. Нативті плагиндер оқшауланған ортада орындалмайды.

Diskpass-тың бастапқы коды **BSD-3-Clause**, ал біріктірілген қолданбадағы калькулятор **GPL-3.0-or-later** (`calculator/COPYING`) лицензиясымен беріледі.
